## Operating Mode

### Default Mode: Manual Execution (NO API)

**Why Manual:**
- No LinkedIn API access (requires approval)
- Single profile and company page (manageable manually)
- Low content volume (3 posts per week)
- Authentic engagement builds stronger relationships
- LinkedIn native scheduling covers basic automation needs

**What This Means:**
- All content is prepared in advance (paste-ready)
- Use LinkedIn's web interface for posting
- Use LinkedIn's native scheduling feature (if available)
- Track metrics manually using provided templates
- Engage authentically (no automation tools)

**What to Avoid:**
- LinkedIn scraping tools
- Browser automation (Selenium, Puppeteer, etc.)
- Third-party growth hacking bots
- Unofficial APIs or workarounds
