## Support and Troubleshooting

### Common Issues

**Issue: Company page does not appear in dropdown when editing Experience**
- Solution: Wait 10-15 minutes after creating company page, then try again. LinkedIn needs time to index new pages.

**Issue: Banner image is cut off or blurry**
- Solution: Verify dimensions (Personal: 1584 x 396, Company: 1128 x 191). Use PNG for best quality.

**Issue: Skills not showing in order**
- Solution: Drag and drop skills to reorder. Top 3 skills display most prominently.

**Issue: Featured section not visible**
- Solution: Add profile section → Recommended → Featured. Must manually add if not visible by default.

**Issue: Cannot pin post to company page**
- Solution: Only admins can pin posts. Verify you are logged in as admin. Post must be published (not scheduled) to pin.
