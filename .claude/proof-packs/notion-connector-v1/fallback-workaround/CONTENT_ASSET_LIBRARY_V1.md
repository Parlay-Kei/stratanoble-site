## Content Templates

### 1. LinkedIn Thought Leadership Post
```
Template Structure:
- Hook (attention-grabbing opening)
- Context (industry/market situation)
- Insight (unique perspective or data)
- Action (what readers should do)
- Engagement (question or call-to-action)

Character Limit: 3000 characters
Optimal Length: 1200-1500 characters
Hashtags: 3-5 relevant industry hashtags
```

### 2. Instagram Visual Post
```
Template Structure:
- Visual (high-quality image/graphic)
- Caption (storytelling format)
- Hashtags (20-30 mixed hashtags)
- Call-to-Action (clear next step)

Aspect Ratio: 1:1 (square) or 4:5 (portrait)
Image Quality: Minimum 1080x1080px
Story Elements: Behind-scenes, educational, inspirational
```

### 3. Twitter/X Engagement Thread
```
Template Structure:
- Thread starter (compelling hook)
- Supporting tweets (2-5 tweets)
- Conclusion (summary + CTA)
- Engagement tweet (question/poll)

Character Limit: 280 per tweet
Thread Length: 3-7 tweets optimal
Visual Elements: Images, GIFs, or video clips
```

### 4. Educational Blog Article
```
Template Structure:
- SEO-optimized headline
- Introduction (problem statement)
- Main content (3-5 sections)
- Conclusion (key takeaways)
- Call-to-action (next steps)

Word Count: 1500-2500 words
SEO Elements: Target keyword, meta description
Internal Links: 3-5 relevant internal links
External Links: 2-3 authoritative sources
```
