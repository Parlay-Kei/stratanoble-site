## Guard Implementation

### Core Protection Logic

```javascript
// Receipt emission guard configuration
const EmissionGuard = {
  MAX_RECEIPTS_PER_MINUTE: 10,
  MAX_RECEIPTS_PER_HOUR: 100,
  EMERGENCY_HALT_THRESHOLD: 50, // In 30 seconds
  GUARD_CHECK_INTERVAL: 5000, // Check every 5 seconds
  RECEIPTS_DIR: 'C:\\Dev\\.claude-anx\\receipts'
};

class ReceiptEmissionGuard {
  constructor() {
    this.recentWrites = [];
    this.halted = false;
    this.haltedAt = null;
    this.totalSuppressed = 0;
  }

  async writeReceipt(filename, content, metadata = {}) {
    // Check if halted
    if (this.halted) {
      this.totalSuppressed++;
      console.warn(`[GUARD] Receipt emission halted. Suppressed: ${this.totalSuppressed}`);
      return false;
    }

    // Add timestamp to recent writes
    const now = Date.now();
    this.recentWrites.push({ timestamp: now, filename, metadata });

    // Clean old entries (keep last hour)
    this.recentWrites = this.recentWrites.filter(
      w => now - w.timestamp < 3600000
    );

    // Check emergency threshold (50 in 30 seconds)
    const last30Seconds = this.recentWrites.filter(
      w => now - w.timestamp < 30000
    );

    if (last30Seconds.length >= EmissionGuard.EMERGENCY_HALT_THRESHOLD) {
      await this.emergencyHalt('RUNAWAY_DETECTED', {
        receiptsIn30Seconds: last30Seconds.length,
        lastReceipts: last30Seconds.slice(-10).map(w => w.filename)
      });
      return false;
    }

    // Check rate limits
    const lastMinute = this.recentWrites.filter(
      w => now - w.timestamp < 60000
    );
    const lastHour = this.recentWrites.length;

    if (lastMinute.length >= EmissionGuard.MAX_RECEIPTS_PER_MINUTE) {
      console.warn(`[GUARD] Minute rate limit reached: ${lastMinute.length}`);
      await this.writeThrottleReceipt('MINUTE_LIMIT', lastMinute.length);
      return false;
    }

    if (lastHour >= EmissionGuard.MAX_RECEIPTS_PER_HOUR) {
      console.warn(`[GUARD] Hour rate limit reached: ${lastHour}`);
      await this.writeThrottleReceipt('HOUR_LIMIT', lastHour);
      return false;
    }

    // Allow write
    try {
      const filepath = path.join(EmissionGuard.RECEIPTS_DIR, filename);
      await fs.writeFile(filepath, content);
      return true;
    } catch (error) {
      console.error(`[GUARD] Failed to write receipt: ${error.message}`);
      return false;
    }
  }

  async emergencyHalt(reason, details) {
    if (this.halted) return;

    this.halted = true;
    this.haltedAt = new Date();

    const haltReceipt = `# RECEIPT EMISSION EMERGENCY HALT

**Date:** ${this.haltedAt.toISOString()}
**Reason:** ${reason}
**Action:** All receipt emission stopped to protect filesystem

## Trigger Details

${JSON.stringify(details, null, 2)}

## Statistics at Halt

- Receipts in last 30 seconds: ${details.receiptsIn30Seconds}
- Receipts in last minute: ${this.recentWrites.filter(w => Date.now() - w.timestamp < 60000).length}
- Receipts in last hour: ${this.recentWrites.length}

## Recent Receipt Files

${details.lastReceipts.join('\n')}

## Recovery Instructions

1. Identify root cause of runaway receipts
2. Fix the underlying issue
3. Clear halted state: delete RECEIPT_EMISSION_HALTED.md
4. Restart supervisor or affected service

## Protection Active

**NO FURTHER RECEIPTS WILL BE WRITTEN UNTIL MANUAL INTERVENTION**

---
Generated by: Receipt Emission Guard
Protection Level: EMERGENCY`;

    // Force write the halt receipt directly
    const haltFile = path.join(EmissionGuard.RECEIPTS_DIR, 'RECEIPT_EMISSION_HALTED.md');
    await fs.writeFile(haltFile, haltReceipt);

    console.error('[GUARD] *** EMERGENCY HALT TRIGGERED ***');
    console.error(`[GUARD] Reason: ${reason}`);
    console.error(`[GUARD] ${details.receiptsIn30Seconds} receipts in 30 seconds`);
    console.error('[GUARD] See RECEIPT_EMISSION_HALTED.md for details');
  }

  async writeThrottleReceipt(limitType, count) {
    const throttleContent = `# Receipt Emission Throttled

**Date:** ${new Date().toISOString()}
**Limit Type:** ${limitType}
**Count:** ${count}

Receipt emission temporarily throttled due to rate limits.
This is normal protection behavior.`;

    const filename = `RECEIPT_THROTTLE_${Date.now()}.md`;
    const filepath = path.join(EmissionGuard.RECEIPTS_DIR, filename);

    try {
      await fs.writeFile(filepath, throttleContent);
    } catch (error) {
      console.error('[GUARD] Could not write throttle receipt');
    }
  }

  getStats() {
    const now = Date.now();
    return {
      halted: this.halted,
      haltedAt: this.haltedAt,
      totalSuppressed: this.totalSuppressed,
      lastMinute: this.recentWrites.filter(w => now - w.timestamp < 60000).length,
      lastHour: this.recentWrites.length,
      oldestTracked: this.recentWrites[0]?.timestamp
        ? new Date(this.recentWrites[0].timestamp).toISOString()
        : null
    };
  }

  clearHalt() {
    if (!this.halted) return false;

    this.halted = false;
    this.haltedAt = null;
    this.totalSuppressed = 0;
    console.log('[GUARD] Emergency halt cleared - emission resumed');
    return true;
  }
}
```

## Integration with Supervisor

### Modified writeSystemReceipt Function

```javascript
// In anx_supervisor.js
const receiptGuard = new ReceiptEmissionGuard();

async writeSystemReceipt(eventType, details) {
  const timestamp = new Date().toISOString().replace(/[:.]/g, '-');
  const filename = `SYSTEM_${eventType}_${timestamp}.md`;

  const content = `# SYSTEM Receipt - ${eventType}
[... rest of content ...]`;

  // Use guard for all receipt writes
  const written = await receiptGuard.writeReceipt(filename, content, {
    eventType,
    service: details.service || 'supervisor'
  });

  if (written) {
    console.log(`[SUPERVISOR] Written ${eventType} receipt: ${filename}`);
  } else {
    console.warn(`[SUPERVISOR] Receipt suppressed by guard: ${filename}`);
  }
}
```

## Filesystem Protection Features

### 1. Rate Limiting Tiers
- **Minute limit:** 10 receipts max
- **Hour limit:** 100 receipts max
- **Emergency threshold:** 50 in 30 seconds

### 2. Emergency Halt
- Triggers on runaway detection
- Writes single RECEIPT_EMISSION_HALTED.md
- Blocks ALL further receipts
- Requires manual intervention

### 3. Statistics Tracking
```javascript
// Periodic stats output
setInterval(() => {
  const stats = receiptGuard.getStats();
  if (stats.lastMinute > 5 || stats.halted) {
    console.log('[GUARD] Stats:', JSON.stringify(stats, null, 2));
  }
}, 30000); // Every 30 seconds
```

## Recovery Procedures

### When RECEIPT_EMISSION_HALTED.md Exists

1. **Check the halt receipt for root cause**
   ```bash
   type .claude-anx\receipts\RECEIPT_EMISSION_HALTED.md
   ```

2. **Review recent receipts**
   ```bash
   dir .claude-anx\receipts\*.md /o-d | head -20
   ```

3. **Fix underlying issue** (usually supervisor bug)

4. **Clear the halt**
   ```bash
   del .claude-anx\receipts\RECEIPT_EMISSION_HALTED.md
   ```

5. **Restart supervisor**
   ```bash
   node .claude-anx\tools\command-center\supervisor\anx_supervisor.js
   ```
