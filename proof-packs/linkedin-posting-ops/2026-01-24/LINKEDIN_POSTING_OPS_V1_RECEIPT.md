## Agent Capabilities

### 1. Queue Generation (`queue` command)

Pulls from Notion where:
- Platform = LinkedIn
- Status = Scheduled OR Approved to Post
- Publish Date <= today + 1 day

Generates `POST_APPROVAL_QUEUE.md` with:
- Title, full post body, planned publish time
- Link back to Notion row
- Validation status (READY, APPROVED, BLOCKED)

### 2. Hard Blocks (Guardrails)

| Block Type | Trigger | Behavior |
|------------|---------|----------|
| BODY_MISSING | Body empty or < 20 chars | Status = BLOCKED |
| ALREADY_POSTED | Asset Link exists in Notion | Status = BLOCKED |
| COOLDOWN_ACTIVE | < 4 hours since last post | Status = BLOCKED |
| FUTURE_DATE | Publish date > tomorrow | Status = BLOCKED |

### 3. Draft Mode (`draft --id=X`)

- Opens LinkedIn company page admin
- Creates post in composer
- Captures proof screenshot
- Closes without posting
- Updates queue with draft status

### 4. Publish Mode (`publish --id=X`)

REQUIRES: Notion Status = "Approved to Post"

Flow:
1. Verify approval status in Notion
2. Navigate to company page
3. Create post
4. Click Post button
5. Capture post URL
6. Update Notion:
   - Status = Posted
   - Asset Link = post URL
   - Posted At = timestamp
7. Generate publish receipt

### 5. Status Check (`status` command)

Shows all runs for today with queue counts.

## Guardrails Implemented

| Guardrail | Location | Description |
|-----------|----------|-------------|
| Approval-Gated | `publishPost()` | Checks `post.status === 'APPROVED'` before any publish |
| No Edits/Deletes | N/A | Not implemented - requires explicit directive |
| One Post Per Approval | Cooldown + single publish call | Rate limited by design |
| Receipt Per Post | `generatePublishReceipt()` | Every publish generates receipt |
| Notion Sync | `updateNotionAfterPublish()` | Status + URL updated after success |

## Usage

```bash
# Generate approval queue from Notion
npx ts-node linkedin-posting-ops.ts queue

# Create draft (no publish) for review
npx ts-node linkedin-posting-ops.ts draft --id=post-mock-001

# Publish approved post
npx ts-node linkedin-posting-ops.ts publish --id=post-mock-001

# Check today's runs
npx ts-node linkedin-posting-ops.ts status
```
