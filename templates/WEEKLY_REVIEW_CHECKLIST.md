# Q-ICMS Weekly Review Checklist

Use this checklist to execute the weekly operating rhythm consistently. Copy this template each week or check items directly in your task manager.

---

## Monday: Project & Milestone Review (30 min)

**Time Block**: Monday 9:00 AM
**Owner**: Product Ops

### Pre-Work (5 min)
- [ ] Open Q-ICMS project dashboard
- [ ] Have last week's status available for comparison
- [ ] Note any major events from last week

### Review Active Projects (15 min)
For each active project:
- [ ] Check last update date (flag if >7 days)
- [ ] Update milestone status: On Track / At Risk / Blocked
- [ ] Review deliverable progress
- [ ] Note any blockers or risks
- [ ] Update completion % if applicable

### Administrative Actions (10 min)
- [ ] Add new projects started last week
- [ ] Archive completed milestones
- [ ] Update next milestone dates if schedule shifted
- [ ] Create follow-up tasks for at-risk items
- [ ] Flag any projects needing stakeholder sync

### Output Check
- [ ] All active projects have status updated
- [ ] No projects with stale data (>7 days)
- [ ] Clear list of at-risk items with owners
- [ ] Next milestones dated

---

## Wednesday: Invoice & Payment Follow-Up (20 min)

**Time Block**: Wednesday 10:00 AM
**Owner**: Finance Ops

### Pre-Work (3 min)
- [ ] Open Q-ICMS invoice tracker
- [ ] Pull aging report (0-7, 8-14, 15-30, 30+ days)
- [ ] Have client contact list ready

### 24 Hour Invoice Sent Confirmation (2 min)
For each invoice with status Sent in the last 24 hours:
- [ ] Confirm recipient contact matches Contacts record
- [ ] Confirm delivery method recorded (email, portal link, other)
- [ ] Confirm comm log entry exists noting invoice sent and due date
- [ ] If not confirmed, create action item for Finance Ops same day

### Review Outstanding Invoices (10 min)
For each outstanding invoice:
- [ ] Check days outstanding
- [ ] Update status: Sent / Acknowledged / In Process / Paid / Overdue
- [ ] **7-14 days**: Send soft follow-up email
- [ ] **14-30 days**: Send formal follow-up (use template)
- [ ] **30+ days**: Escalate to client lead + log in Q-ICMS
- [ ] Record any payment receipts from last 7 days

### Administrative Actions (5 min)
- [ ] Close paid invoices (move to archive)
- [ ] Create follow-up tasks for overdue invoices
- [ ] Flag any disputes or blockers
- [ ] Update cash flow forecast if needed
- [ ] Note any payment patterns or concerns

### Output Check
- [ ] All invoices have current status
- [ ] Follow-ups sent for 14+ day invoices
- [ ] Paid invoices archived
- [ ] Clear escalation list with dates

---

## Friday: Comms Log & Next Actions (20 min)

**Time Block**: Friday 4:00 PM
**Owner**: Product Ops / Project Lead

### Pre-Work (3 min)
- [ ] Review sent emails from the week
- [ ] Check meeting notes and decisions
- [ ] Have Q-ICMS project list open

### Log Weekly Decisions (8 min)
For each major decision this week:
- [ ] Summarize decision in Q-ICMS (2-3 sentences)
- [ ] Link to project/contract
- [ ] Note decision maker and date
- [ ] Document rationale if non-obvious
- [ ] Tag related stakeholders

Examples of "major decisions":
- Scope changes
- Budget approvals
- Timeline shifts
- Vendor selections
- Policy changes

### Update Next Actions (9 min)
For each active project:
- [ ] Review this week's action items (mark complete)
- [ ] Add next week's actions with due dates
- [ ] Assign owners to each action
- [ ] Flag any actions needing Monday follow-up
- [ ] Archive completed actions

### Output Check
- [ ] Key decisions documented with context
- [ ] Each project has next actions with owners
- [ ] Completed actions archived
- [ ] Monday priorities clearly flagged

## Monthly Audit (Last Friday, +10 min)

Run these checks on the last Friday of each month:

### Data Quality
- [ ] % of projects updated in last 7 days: _____%
- [ ] Average invoice aging: _____ days
- [ ] % of actions completed on time: _____%
- [ ] # of decisions logged this month: _____

### Process Health
- [ ] Was rhythm followed all 4 weeks? (Y/N)
- [ ] Any recurring blockers?
- [ ] Is Q-ICMS the source of truth for decisions? (Y/N)
- [ ] What could be streamlined?

### Adjustments
- [ ] Update rhythm document if needed
- [ ] Adjust time blocks if sessions run long
- [ ] Add/remove checklist items based on usage
- [ ] Share wins and improvements with team

## Quick Reference

| Day | Focus | Time | Key Output |
|-----|-------|------|------------|
| Mon | Projects & Milestones | 30m | Current portfolio status |
| Wed | Invoices & Payments | 20m | Clean payment pipeline |
| Fri | Decisions & Actions | 20m | Action log + next week priorities |

**Total Weekly Investment**: 70 minutes
**ROI**: Always-current project status, faster payments, better decision tracking

---

## Tips for Success

**Do**:
- Cadence reminders are automated for Mon 9:00, Wed 10:00, Fri 16:00 America/Los_Angeles
- Keep sessions time-boxed (set timer)
- Focus on updates, not deep work
- Use templates for follow-up emails
- Celebrate completed milestones

**Don't**:
- Skip weeks (compounds quickly)
- Try to solve problems during review (create follow-up task instead)
- Update everything (focus on active projects only)
- Let sessions run long (protect the 70-minute budget)

## Email Templates

### Invoice Follow-Up (7-14 days)
```
Subject: Quick check-in: Invoice [NUMBER]

Hi [Name],

Just checking in on Invoice [NUMBER] sent on [DATE] for [PROJECT/DELIVERABLE].

Let me know if you need anything to process payment or if there are any questions.

Thanks,
[Your Name]
```

### Invoice Follow-Up (14+ days - Formal)
```
Subject: Payment follow-up: Invoice [NUMBER] (Issued [DATE])

Hi [Name],

Following up on Invoice [NUMBER] issued on [DATE] for [PROJECT/DELIVERABLE].

Payment was expected by [DUE DATE]. Could you provide a status update and expected payment date?

Please let me know if there are any issues or if documentation is needed.

Thanks,
[Your Name]
```
