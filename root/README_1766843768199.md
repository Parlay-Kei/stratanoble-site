# ACHIEVERY Visual Assets

This directory contains optimized image assets for the ACHIEVERY preview page and marketing materials.

## Available Assets

### Dashboard Mockups
- **dashboard-free-tier.{svg,png,webp}** - Free tier dashboard showing limitations and upgrade prompts
- **dashboard-growth-tier.{svg,png,webp}** - Pro tier dashboard with full AI features and progress tracking
- **dashboard-partner-tier.{svg,png,webp}** - Enterprise tier with coaching integration and team features

### Interface Designs
- **signin-interface.{svg,png,webp}** - Professional sign-in page with Strata Noble integration
- **mobile-responsive-demo.{svg,png,webp}** - Mobile experience showcase across three devices
- **tier-comparison-grid.{svg,png,webp}** - Complete subscription comparison chart

## Brand Guidelines

### Colors
- **Navy Primary**: #001122 → #002244 (gradient)
- **Emerald CTA**: #50C878 → #40B768 (gradient)
- **Gold Premium**: #fbbf24 → #f59e0b (Enterprise tier)
- **Silver Basic**: #f1f5f9 → #e2e8f0 (Free tier)

### Typography
- **Headings**: Arial, sans-serif, bold weights
- **Body**: Arial, sans-serif, regular/medium weights
- **Professional tone**: Executive appeal, no gamification language

## Usage in Next.js

### With next/image (Recommended)
```tsx
import Image from 'next/image';

<Image
  src="/images/achievery/dashboard-growth-tier.png"
  alt="ACHIEVERY Pro dashboard showing AI-powered features"
  width={800}
  height={600}
  className="rounded-lg shadow-lg"
  priority // for above-the-fold images
/>
```

### With OptimizedImage Component
```tsx
import OptimizedImage from '@/components/OptimizedImage';

<OptimizedImage
  src="/images/achievery/dashboard-growth-tier.png"
  alt="ACHIEVERY Pro dashboard"
  width={800}

  className="rounded-lg shadow-lg"
/>
```

## File Formats

- **SVG**: Original vector files (editable)
- **PNG**: High-quality raster (1200px width)
- **WebP**: Optimized for web (85% quality, modern browsers)

## Optimization

Run `npm run optimize-images` to regenerate PNG and WebP versions from SVG sources.

## Design Principles

1. **Professional First**: Target 25-45 working professionals
2. **No Gamification**: Clean, business-focused interface
3. **Clear Value Prop**: Show transformation from activity to achievement
4. **Progressive Disclosure**: Free → Pro → Enterprise feature progression
5. **Mobile Responsive**: Touch-friendly interface design
