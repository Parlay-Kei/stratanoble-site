## 🔒 Document Governance

### Single Source of Truth
The **main PRD.md** is the canonical product requirements document. All other PRDs are supplementary and extend (not replace) the main PRD.

### Version Control
- All PRDs are version-controlled in this repository
- Updates require pull requests with reviewer approval
- Use the [PR template](../../.github/PULL_REQUEST_TEMPLATE/default.md)

### Cross-References
When referencing product requirements:
- ✅ **Correct**: "See main PRD.md for core platform features"
- ❌ **Incorrect**: Copying content from PRD into other documents

### Update Process
1. Identify which PRD needs updating (main vs. supplementary)
2. Create feature branch
3. Update appropriate PRD(s)
4. Submit PR with clear change summary
5. Get review approval
6. Merge and update "Last Updated" date
