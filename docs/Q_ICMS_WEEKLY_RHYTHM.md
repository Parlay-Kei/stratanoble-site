# Q-ICMS Weekly Operating Rhythm

**Mission ID**: OCS-Q-ICMS-WEEKLY-RHYTHM-0007
**Objective**: Establish a sustainable weekly cadence to keep Q-ICMS current and make it the default location for project decisions, contracts, and operational tracking.

---

## Overview

Q-ICMS (Internal Contract Management System) serves as the single source of truth for:
- Active projects and milestones
- Contract status and deliverables
- Invoice tracking and payment follow-up
- Decision logs and communications
- Next actions and accountability

This weekly rhythm ensures Q-ICMS remains current, actionable, and trusted.

---

## Weekly Cadence

### Monday: Project & Milestone Review
**Time**: 30 minutes
**Owner**: Product Ops
**Objective**: Ensure all active projects reflect current status

**Actions**:
1. Review all active projects in Q-ICMS
2. Update milestone statuses (On Track / At Risk / Blocked)
3. Flag any projects with stale updates (>7 days)
4. Add new projects or milestones from last week
5. Archive completed milestones
6. Update next milestone dates if needed

**Output**: Current project portfolio view with accurate status indicators

---

### Wednesday: Invoice & Payment Follow-Up
**Time**: 20 minutes
**Owner**: Finance Ops
**Objective**: Keep payment pipeline moving and identify blockers

**Actions**:
1. Review all outstanding invoices in Q-ICMS
2. Check payment status for invoices >7 days old
3. Send follow-up for invoices >14 days old (overdue trigger)
4. Update invoice status (Sent / Acknowledged / Paid / Overdue)
5. Flag any payment blockers or disputes
6. Record payment receipts and close paid invoices

**Output**: Clean invoice pipeline with clear follow-up actions

**Overdue Triggers**:
- **7 days**: Soft follow-up (status check)
- **14 days**: Formal follow-up required
- **30 days**: Escalation to client lead

---

### Friday: Comms Log & Next Actions
**Time**: 20 minutes
**Owner**: Product Ops / Project Lead
**Objective**: Capture weekly decisions and set next week's priorities

**Actions**:
1. Review comms log for the week (emails, meetings, decisions)
2. Log key decisions made this week in Q-ICMS
3. Update next actions for each active project
4. Assign owners for next week's actions
5. Flag any items needing follow-up Monday
6. Archive completed action items

**Output**: Clear action log with ownership and weekly decisions documented

---

## Success Metrics

Track these monthly to ensure cadence effectiveness:

1. **Staleness**: % of projects with updates <7 days old (Target: >90%)
2. **Invoice Velocity**: Average days from invoice sent to payment (Target: <14 days)
3. **Action Completion**: % of next actions completed on time (Target: >85%)
4. **Decision Coverage**: # of major decisions logged per month (Target: Track trend)

---

## Principles

1. **Minimal Viable Discipline**: Each session <30 minutes
2. **Action-Oriented**: Every review produces clear next steps
3. **Single Source of Truth**: If it's not in Q-ICMS, it doesn't exist
4. **Ownership Clear**: Every item has an owner
5. **Weekly Commitment**: Miss once = email update; miss twice = calendar block

## Getting Started

**Week 1 Setup**:
1. Block calendar: Mon 9:00, Wed 10:00, Fri 16:00
2. Create initial project list in Q-ICMS
3. Import current invoices and status
4. Set up comms log template
5. Run first rhythm cycle

## Troubleshooting

**"I don't have time for three sessions"**
→ Combine Monday + Friday (45 min), keep Wednesday separate for finance

**"Q-ICMS is getting stale again"**
→ Check who missed their day; send template checklist; offer 1:1 pairing

**"Too many projects to review"**
→ Focus on active projects only; archive completed; defer future projects

**"Decisions aren't being logged"**
→ Add "Log in Q-ICMS" as last item on meeting agendas
