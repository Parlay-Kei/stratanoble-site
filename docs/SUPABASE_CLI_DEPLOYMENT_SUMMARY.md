## 🔧 **DEPLOYMENT EXECUTION PATHS**

### **Path 1: Manual Database Migration (Recommended - 15 minutes)**
1. **Copy SQL:** From `migration-output.txt`
2. **Supabase Dashboard:** Paste and execute in SQL Editor
3. **Update .env:** Add Supabase credentials
4. **Test:** Submit discovery form and verify lead creation

### **Path 2: Supabase CLI Migration (Advanced - 30 minutes)**
1. **Start Docker Desktop:** Required for local Supabase
2. **Run:** `npx supabase start`
3. **Link Project:** `npx supabase link --project-ref YOUR_PROJECT_ID`
4. **Push Migrations:** `npx supabase db push`

### **Path 3: Production Direct (Enterprise - 45 minutes)**
1. **Supabase Project Setup:** Create new project or use existing
2. **Database Migration:** Apply via dashboard or CLI
3. **Environment Configuration:** Production credentials
4. **Load Testing:** Full integration and performance testing
