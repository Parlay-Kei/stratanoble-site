## Layout Templates

### Social Media Layouts

**Instagram Carousel (1080x1080px):**
- Slide 1: Bold hook + minimal design
- Slides 2-8: One key point per slide, plenty of white space
- Slide 9: CTA with clear action
- Brand colors + consistent fonts

**LinkedIn Post (1200x628px):**
- Professional, data-driven
- Clear hierarchy: Headline → Body → Source
- Use branded color blocks sparingly

**TikTok/Reel Thumbnail (1080x1920px):**
- Eye-catching hook in top third
- Readable text (large, bold)
- Face/person if relevant
- High contrast

**YouTube Thumbnail (1280x720px):**
- Readable title text (even at small size)
- Expressive facial thumbnail (if using person)
- Branded color element
- Avoid clutter

## Accessibility Guidelines

### Color Contrast
- Text on background: Minimum 4.5:1 ratio
- Large text: Minimum 3:1 ratio
- Use WebAIM Contrast Checker

### Text Readability
- Font size: Minimum 16px for body text
- Line spacing: 1.5x font size
- Paragraph width: Max 75 characters

### Video Accessibility
- Always include captions
- Use legible fonts (sans-serif, min 24pt)
- High contrast text
- Avoid flashing lights (max 3 flashes/sec)
