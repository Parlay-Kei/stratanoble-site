## 🎨 Design Specifications

### Instagram Feed Post
**Dimensions:** 1080 x 1080px (square) or 1080 x 1350px (portrait)
**Format:** PNG or JPG
**File size:** Under 1MB
**Color mode:** RGB

**Design Guidelines:**
- Bold, eye-catching visuals
- Text readable at thumbnail size
- Leave breathing room
- Brand colors prominent
- Logo in bottom corner

---

### Instagram Carousel
**Dimensions:** 1080 x 1080px per slide
**Format:** PNG or JPG
**Slides:** 5-10 typically
**File size:** Under 1MB per slide

**Design Guidelines:**
- Slide 1: Bold hook + minimal text
- Slides 2-9: One key point per slide
- Slide 10: CTA with clear action
- Consistent style throughout
- Visual progression/flow
- Brand colors + fonts throughout

**Carousel Flow:**
1. Hook slide (visual + text)
2. Context/problem
3. Key point 1
4. Key point 2
5. Key point 3
6. Transition/insight
7. Solution/approach
8. Result/outcome
9. Call to action
10. (Optional) "Follow for more"

---

### LinkedIn Post Graphic
**Dimensions:** 1200 x 628px
**Format:** PNG or JPG
**File size:** Under 5MB

**Design Guidelines:**
- Professional aesthetic
- Data-driven when applicable
- Clear hierarchy
- Minimal text
- Brand colors (muted palette)
- White space important

---

### TikTok/Reel Thumbnail
**Dimensions:** 1080 x 1920px (9:16)
**Format:** PNG or JPG
**File size:** Under 1MB

**Design Guidelines:**
- Hook in top third
- Large, bold text
- High contrast
- Face/person if relevant
- Readable at small size
- Vibrant colors

---

### YouTube Thumbnail
**Dimensions:** 1280 x 720px (16:9)
**Format:** JPG
**File size:** Under 2MB

**Design Guidelines:**
- Compelling visual
- Title text (large and readable)
- Facial expression if using person
- Branded color element
- High contrast
- Avoid clutter
- Text takes up max 40% of space

---

### Substack Header
**Dimensions:** 1600 x 840px
**Format:** PNG or JPG
**File size:** Under 1MB

**Design Guidelines:**
- Professional and clean
- Represents essay theme
- Subtle branding
- Text overlay friendly
- Works at various sizes

## ✅ Design Quality Checklist

Before submitting any design:

**Brand Compliance:**
- [ ] Uses only brand colors?
- [ ] Uses approved fonts?
- [ ] Logo placed correctly?
- [ ] Matches brand aesthetic?

**Technical Requirements:**
- [ ] Correct dimensions?
- [ ] Proper file format?
- [ ] Under file size limit?
- [ ] High resolution (min 72dpi)?
- [ ] RGB color mode?

**Design Quality:**
- [ ] Text readable on mobile?
- [ ] High contrast for readability?
- [ ] Visual hierarchy clear?
- [ ] Balanced composition?
- [ ] No design errors/glitches?

**Accessibility:**
- [ ] Color contrast ratio 4.5:1 minimum?
- [ ] Text not over busy backgrounds?
- [ ] Important info not in images only?
