## Deployment Instructions

To activate the landing page revamp:

1. Navigate to Netlify Dashboard
2. Site settings → Environment variables
3. Add: `NEXT_PUBLIC_REVAMP_ENABLED` = `true`
4. Trigger deploy: Deploys → Trigger deploy → Deploy site
5. Verify at https://stratanoble.com
